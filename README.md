# Registro de empleados

Prototipo academico de una pagina web para registrar datos basicos de empleados. El proyecto se utiliza como base para practicar control de versiones remoto, Pull Requests y publicacion con GitHub Pages.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)

## Archivos principales

- `index.html`: estructura de la pagina.
- `estilo.css`: estilos.
- `Empleado.js` y `Contador.js`: clases de empleados.
- `Principal.js` y `registro.js`: scripts de la aplicacion.

## Ejecucion local

Abre `index.html` en un navegador. Antes de usar el formulario, comprueba el estado de las funciones de registro y visualizacion en el codigo fuente.
